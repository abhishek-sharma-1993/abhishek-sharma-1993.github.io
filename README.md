# Abhishek Sharma — Portfolio

Single-file site (`index.html`), no build step.

## Publish on GitHub Pages (free)
1. Create a public repo named exactly `abhishek-sharma-1993.github.io`.
2. Upload `index.html` (and this README) to the repo root.
3. Repo → Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / `(root)` → Save.
4. Your site goes live at https://abhishek-sharma-1993.github.io within a few minutes.

## Optional
- Add your resume as `resume.pdf` in the repo and link to it from the Contact section.
- Custom domain: add it under Settings → Pages → Custom domain.
